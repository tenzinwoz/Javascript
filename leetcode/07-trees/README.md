# Trees (DFS / BFS)

**DFS:** recursion or explicit stack — natural for path/sum/structure checks.  
**BFS:** queue — level-order, shortest path on unweighted tree-like graphs.

**Signals:** “depth,” “path sum,” “same tree,” “level order.”

**Pitfalls:** Null children; confusing height vs depth; stack overflow risk on very deep skewed trees (rare in JS interviews but know the idea).
