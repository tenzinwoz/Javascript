# LeetCode Practice

Algorithm / data-structure interview problems only (LeetCode-style).

JS utilities (debounce, deep clone, etc.) stay in `JS problem solving/` — not here.

## File naming

| File | Meaning |
|------|---------|
| `problem.md` | Prompt / examples |
| `starter.js` | Blank — solve here |
| `solution.js` | Reference (`node solution.js`) |
| `practice.js` | Your earlier attempt (if you had one) |
