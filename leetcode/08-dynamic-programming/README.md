# Dynamic Programming (Intro)

Break problems into **overlapping subproblems** with **optimal substructure**. Cache (**memoization**) or build bottom-up (**tabulation**).

**Signals:** “ways to,” “min/max cost,” “can you reach,” “rob houses in a row.”

**Pitfalls:** Wrong base cases; state definition too vague (define `dp[i]` precisely).
